# 🧩 InfoTEA

## Sobre o Projeto

O InfoTEA é uma plataforma web desenvolvida com o objetivo de promover inclusão, acessibilidade e disseminação de informações sobre o Transtorno do Espectro Autista (TEA).

A plataforma reúne conteúdos educativos, orientações, recursos de apoio e ferramentas que auxiliam pessoas autistas, familiares, cuidadores, educadores e profissionais da saúde.

---

## 🎯 Objetivos

- Promover a inclusão social.
- Disponibilizar informações confiáveis sobre TEA.
- Facilitar o acesso a recursos educacionais.
- Apoiar familiares e cuidadores.
- Contribuir para a conscientização da sociedade.
